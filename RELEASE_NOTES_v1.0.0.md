# Portal Toolkit v1.0.0

First public release of Portal Toolkit.

## Features

- Wi-Fi ADB and USB OTG connection
- APK install support
- Custom APK install
- Photo upload
- Portal app list and uninstall
- Wireless ADB enable flow
- Local network Portal detection
- Basic device status display

## Tested on

- Portal Mini

## APK

- `PortalToolkit-v1.0.0-debug.apk`
