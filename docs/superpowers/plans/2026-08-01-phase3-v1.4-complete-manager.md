# Phase 3 (v1.4) "Complete manager" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a two-way file manager, replace the Photos tab with a screensaver manager, enrich the portal app list with icons/labels, and retrofit real byte-level progress + cancellation onto every transfer.

**Architecture:** A new byte-counting okio `Source`/`Sink` wrapper (`data/transfer/CountingStreams`) is built **first** and becomes the shared progress primitive for all transfers — the codebase currently has no byte progress at all, so this is a foundation, not a retrofit. A shared public error formatter (`data/AdbErrors`) is extracted so new managers report through the existing `AdbError` vocabulary without duplicating the `private formatAdbReason`. The file manager (`data/PortalFileManager`, `viewmodel/FileManagerViewModel`, `ui/tools/files`) lives as a sixth section under the existing Tools `ScrollableTabRow`. The screensaver manager (`data/PortalScreensaverManager`, `viewmodel/ScreensaverViewModel`, `ui/screensaver`) replaces `PhotosTab` at the `photos` route. The rich app list enriches `PortalAppInfo` via a one-time full-APK pull + disk cache. All pure logic (ls-la parser, dedupe matcher, path-safety guard, cache keying) is extracted into non-Android testable units.

**Tech Stack:** Kotlin, Jetpack Compose, Material3, AndroidViewModel + StateFlow, DataStore Preferences, dadb 1.2.6 (via `data/adb/DadbConnections`), okio, kotlinx-coroutines, JUnit 4 + kotlinx-coroutines-test + org.json.

```kotlin
/** Progresul unui transfer de octeti. [totalBytes] <= 0 inseamna dimensiune necunoscuta. */
data class TransferProgress(
    val bytesTransferred: Long,
    val totalBytes: Long
) {
    val isDeterminate: Boolean get() = totalBytes > 0L
    val fraction: Float
        get() = if (totalBytes > 0L) (bytesTransferred.toFloat() / totalBytes).coerceIn(0f, 1f) else 0f
}
```

`CountingStreams.kt`:
```kotlin
package com.portalinstaller.data.transfer

import okio.Buffer
import okio.ForwardingSink
import okio.ForwardingSource
import okio.Sink
import okio.Source

/** Numara octetii cititi dintr-un [Source] si raporteaza progresul incremental. */
fun Source.counting(total: Long, onProgress: (TransferProgress) -> Unit): Source =
    object : ForwardingSource(this) {
        private var transferred = 0L
        override fun read(sink: Buffer, byteCount: Long): Long {
            val read = super.read(sink, byteCount)
            if (read > 0L) {
                transferred += read
                onProgress(TransferProgress(transferred, total))
            }
            return read
        }
    }

/** Numara octetii scrisi intr-un [Sink] si raporteaza progresul incremental. */
fun Sink.counting(total: Long, onProgress: (TransferProgress) -> Unit): Sink =
    object : ForwardingSink(this) {
        private var transferred = 0L
        override fun write(source: Buffer, byteCount: Long) {
            super.write(source, byteCount)
            transferred += byteCount
            onProgress(TransferProgress(transferred, total))
        }
    }
```

```kotlin
package com.portalinstaller.data

import android.content.Context
import com.portalinstaller.R

/** Categorii de erori ADB, mapate la resurse de string in [AdbErrors.formatReason]. */
enum class AdbReasonKey { DEVICE_OFFLINE, CONNECTION_LOST, TIMEOUT, PERMISSION_DENIED, NO_SPACE, INSTALL_FAILED, SECURITY, FALLBACK }

/** Clasifica un mesaj ADB brut fara a atinge resursele Android (testabil pe JVM). */
internal fun classifyAdbReason(rawMessage: String?): AdbReasonKey {
    val m = rawMessage?.lowercase() ?: return AdbReasonKey.FALLBACK
    return when {
        "device offline" in m -> AdbReasonKey.DEVICE_OFFLINE
        "broken pipe" in m || "connection reset" in m || "closed" in m -> AdbReasonKey.CONNECTION_LOST
        "timeout" in m -> AdbReasonKey.TIMEOUT
        "permission denied" in m -> AdbReasonKey.PERMISSION_DENIED
        "no space left" in m -> AdbReasonKey.NO_SPACE
        "install_failed" in m -> AdbReasonKey.INSTALL_FAILED
        "securityexception" in m -> AdbReasonKey.SECURITY
        else -> AdbReasonKey.FALLBACK
    }
}

/** Formatter partajat de erori ADB pentru managerele Phase 3. */
object AdbErrors {
    fun formatReason(context: Context, rawMessage: String?, fallback: String): String =
        when (classifyAdbReason(rawMessage)) {
            AdbReasonKey.DEVICE_OFFLINE -> context.getString(R.string.error_device_offline)
            AdbReasonKey.CONNECTION_LOST -> context.getString(R.string.error_connection_lost)
            AdbReasonKey.TIMEOUT -> context.getString(R.string.error_timeout)
            AdbReasonKey.PERMISSION_DENIED -> context.getString(R.string.error_permission_denied)
            AdbReasonKey.NO_SPACE -> context.getString(R.string.error_no_space)
            AdbReasonKey.INSTALL_FAILED -> rawMessage ?: fallback
            AdbReasonKey.SECURITY -> context.getString(R.string.error_security)
            AdbReasonKey.FALLBACK -> rawMessage?.takeIf { it.isNotBlank() } ?: fallback
        }
}
```

```kotlin
package com.portalinstaller.data.files

/** Parseaza iesirea toybox `ls -la` (stabil pe SDK 29) in [RemoteFile]. */
object LsParser {
    fun parse(parentPath: String, lsOutput: String): List<RemoteFile> =
        lsOutput.lineSequence()
            .map { it.trimEnd() }
            .filter { it.isNotBlank() && !it.startsWith("total ") }
            .mapNotNull { parseLine(parentPath, it) }
            .toList()

    private fun parseLine(parentPath: String, line: String): RemoteFile? {
        // perms links owner group size date time name...  → 8 campuri, restul e numele
        val parts = line.split(Regex("\\s+"), limit = 8)
        if (parts.size < 8) return null
        val perms = parts[0]
        val size = parts[4].toLongOrNull() ?: 0L
        val modifiedAt = "${parts[5]} ${parts[6]}"
        var name = parts[7]
        val isSymlink = perms.startsWith("l")
        if (isSymlink) name = name.substringBefore(" -> ")
        if (name == "." || name == "..") return null
        val isDirectory = perms.startsWith("d")
        val base = parentPath.trimEnd('/')
        return RemoteFile(
            name = name,
            path = "$base/$name",
            isDirectory = isDirectory,
            isSymlink = isSymlink,
            sizeBytes = size,
            modifiedAt = modifiedAt,
            permissions = perms
        )
    }
}
```

```kotlin
package com.portalinstaller.data.files

/** Garda de siguranta: operatiile in afara /sdcard cer "mod avansat". */
object PathSafety {
    const val SDCARD_ROOT = "/sdcard"

    fun isWithinSdcard(path: String): Boolean {
        val normalized = path.trimEnd('/')
        return normalized == SDCARD_ROOT || normalized.startsWith("$SDCARD_ROOT/")
    }

    fun requireAllowed(path: String, advancedMode: Boolean) {
        if (!advancedMode && !isWithinSdcard(path)) {
            throw SecurityException("Operatie interzisa in afara /sdcard fara mod avansat: $path")
        }
    }
}
```

`PortalFileManager.kt` — implement each op. Pattern (quoting paths with a local `shellQuote` helper mirroring the one in `PortalConnectionManager.kt:505`):
```kotlin
package com.portalinstaller.data.files

import dadb.Dadb
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import java.io.File

/** Operatii de fisiere pe Portal prin ADB. Toate ruleaza pe IO. */
class PortalFileManager {

    suspend fun list(dadb: Dadb, path: String): List<RemoteFile> = withContext(Dispatchers.IO) {
        val out = dadb.shell("ls -la ${shellQuote(path)}").allOutput
        LsParser.parse(path, out)
    }

    suspend fun delete(dadb: Dadb, file: RemoteFile, advancedMode: Boolean) = withContext(Dispatchers.IO) {
        PathSafety.requireAllowed(file.path, advancedMode)
        // Directoare doar goale (fara -r): rmdir esueaza daca nu e gol.
        val cmd = if (file.isDirectory) "rmdir ${shellQuote(file.path)}" else "rm ${shellQuote(file.path)}"
        val resp = dadb.shell(cmd)
        require(resp.exitCode == 0) { resp.allOutput }
    }

    suspend fun rename(dadb: Dadb, file: RemoteFile, newName: String, advancedMode: Boolean) = withContext(Dispatchers.IO) {
        PathSafety.requireAllowed(file.path, advancedMode)
        val dest = "${file.path.substringBeforeLast('/')}/$newName"
        val resp = dadb.shell("mv ${shellQuote(file.path)} ${shellQuote(dest)}")
        require(resp.exitCode == 0) { resp.allOutput }
    }

    suspend fun move(dadb: Dadb, file: RemoteFile, destDir: String, advancedMode: Boolean) = withContext(Dispatchers.IO) {
        PathSafety.requireAllowed(file.path, advancedMode)
        PathSafety.requireAllowed(destDir, advancedMode)
        val dest = "${destDir.trimEnd('/')}/${file.name}"
        val resp = dadb.shell("mv ${shellQuote(file.path)} ${shellQuote(dest)}")
        require(resp.exitCode == 0) { resp.allOutput }
    }

    suspend fun mkdir(dadb: Dadb, parentPath: String, name: String, advancedMode: Boolean) = withContext(Dispatchers.IO) {
        val dest = "${parentPath.trimEnd('/')}/$name"
        PathSafety.requireAllowed(dest, advancedMode)
        val resp = dadb.shell("mkdir ${shellQuote(dest)}")
        require(resp.exitCode == 0) { resp.allOutput }
    }

    suspend fun pull(dadb: Dadb, file: RemoteFile, localDir: File, advancedMode: Boolean): File = withContext(Dispatchers.IO) {
        PathSafety.requireAllowed(file.path, advancedMode)
        val local = File(localDir, file.name)
        dadb.pull(local, file.path)
        local
    }

    suspend fun push(dadb: Dadb, localFile: File, destDir: String, advancedMode: Boolean): String = withContext(Dispatchers.IO) {
        PathSafety.requireAllowed(destDir, advancedMode)
        val remote = "${destDir.trimEnd('/')}/${localFile.name}"
        try {
            dadb.push(localFile, remote)
        } catch (e: Exception) {
            // Curatare push partial: sterge fisierul remote incomplet.
            runCatching { dadb.shell("rm ${shellQuote(remote)}") }
            throw e
        }
        remote
    }

    private fun shellQuote(arg: String): String = "'" + arg.replace("'", "'\\''") + "'"
}
```
> **dadb `pull`/`push` byte progress:** dadb 1.2.6's `pull(File, String)`/`push(File, String)` defaults do not expose a progress callback. For v1.4, per-file byte progress on file-manager transfers is best-effort: report indeterminate (via `TransferProgress(0, file.sizeBytes)` at start, then `TransferProgress(sizeBytes, sizeBytes)` on completion) unless a lower-level `AdbStream`-based transfer is wired. **Do NOT block this task on byte-accurate mid-transfer progress** — the counting primitive (Task S) is applied where okio streams are directly controlled (Task Z APK pulls, thumbnail pulls). Keep the `onProgress` params in the ViewModel layer (Task W) reporting file-count + start/end byte markers.
